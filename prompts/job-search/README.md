# Job search prompts

Resume rewrites, role targeting, outreach, and application strategy.

| ID | Title | Status | When to use |
| --- | --- | --- | --- |
| `job-search/rewrite-resume-for-callbacks` | Resume conversion fixer | draft | Rewrite a full resume for callbacks and ATS |
| `job-search/match-resume-to-job` | Job description matcher | draft | Tailor a resume to one posting without inventing fit |
| `job-search/find-overlooked-roles` | Role fit finder | draft | Rank 10 overlooked titles by demand and reply odds |
| `job-search/upgrade-resume-bullets` | Bullet point upgrader | draft | Tighten existing bullets to under two lines each |
| `job-search/personalize-cover-letter` | Cover letter personalizer | draft | Write a short, specific letter for one role |
| `job-search/write-recruiter-hook` | Recruiter hook message | draft | Draft a LinkedIn or email opener that asks for a reply |
| `job-search/optimize-job-applications` | Application optimizer | draft | Plan weekly volume, customization, and follow-up |
